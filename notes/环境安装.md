本项目推荐用 `uv` 安装和运行，实际 Python 版本要求是 **Python 3.10.x**，因为 `pyproject.toml` 写的是：

```toml
requires-python = ">=3.10, <3.11"
```

**1. 安装前准备**

需要先安装：

```bash
brew install ffmpeg libsndfile git
```

如果还没有 `uv`：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

然后在项目目录执行：

```bash
cd /Users/admin/Downloads/pyvideotrans_pro
uv sync
```

**2. 启动桌面版**

桌面版功能最完整：

```bash
uv run sp.py
```

如果要指定界面语言：

```bash
uv run sp.py --lang zh
```

**3. 使用命令行**

项目 CLI 入口是 `cli.py`，支持四类任务：

```bash
uv run cli.py --task stt --name "/path/to/video.mp4"
```

常用示例：

```bash
# 视频/音频转字幕
uv run cli.py --task stt --name "./demo.mp4"

# 字幕翻译
uv run cli.py --task sts --name "./demo.srt" --target_language_code en

# 字幕配音
uv run cli.py --task tts --name "./demo.srt" --voice_role "zh-CN-YunyangNeural"

# 完整视频翻译
uv run cli.py --task vtv --name "./demo.mp4" --source_language_code zh-cn --target_language_code en --voice_role "en-US-GuyNeural"
```

查看可用渠道：

```bash
uv run cli.py --list providers
uv run cli.py --list languages
uv run cli.py --list models
```

**4. 启动 WebUI**

WebUI 需要额外安装 Gradio：

```bash
uv sync --extra webui
uv run webui.py
```

默认访问：

```text
http://127.0.0.1:7860
```

指定端口：

```bash
uv run webui.py --port 8080
```

**5. 输出位置**

默认结果一般会输出到项目下的：

```text
output/
```

运行中产生的日志在：

```text
logs/
```

推荐你先用桌面版：

```bash
uv run sp.py
```

如果只是批量处理或服务器运行，再用 `cli.py`。
