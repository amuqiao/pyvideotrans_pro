本项目推荐用 `uv` 安装和运行，实际 Python 版本要求是 **Python 3.10.x**，因为 `pyproject.toml` 写的是：

```toml
requires-python = ">=3.10, <3.11"
```

**1. 安装前准备**

需要先安装：

```bash
brew install ffmpeg libsndfile git
```

如果还没有 `uv`：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

然后在项目目录执行：

```bash
cd /Users/admin/Downloads/pyvideotrans_pro
uv sync
```

**2. macOS 原生依赖检查**

macOS 上部分语音渠道会通过 Python 包调用系统动态库。例如 Qwen3-TTS 试听会加载 `soundfile`，而 `soundfile` 需要找到 `libsndfile.dylib`。

先确认 `soundfile` 能正常加载：

```bash
.venv/bin/python -c "import soundfile as sf; print(sf.__libsndfile_version__)"
```

如果报错包含以下信息：

```text
ctypes.util.find_library() did not manage to locate a library called 'sndfile'
cannot load library '_soundfile_data/libsndfile.dylib'
```

先确认 Homebrew 依赖已安装：

```bash
brew install libsndfile
```

如果 `_soundfile_data` 目录里存在 `libsndfile_arm64.dylib`，优先补同目录链接：

```bash
ln -sf libsndfile_arm64.dylib .venv/lib/python3.10/site-packages/_soundfile_data/libsndfile.dylib
.venv/bin/python -c "import soundfile as sf; print(sf.__libsndfile_version__)"
```

如果当前环境没有这个 arm64 动态库，再用 Homebrew 动态库路径启动：

```bash
DYLD_LIBRARY_PATH=/opt/homebrew/lib uv run sp.py --lang zh
```

或者给当前虚拟环境链接到 Homebrew 的动态库：

```bash
mkdir -p .venv/lib/python3.10/site-packages/_soundfile_data
ln -sf /opt/homebrew/opt/libsndfile/lib/libsndfile.dylib .venv/lib/python3.10/site-packages/_soundfile_data/libsndfile.dylib
.venv/bin/python -c "import soundfile as sf; print(sf.__libsndfile_version__)"
```

如果以后删除并重建 `.venv`，需要重新执行上面的链接命令。

更多试听无声、PortAudio 输出设备、蓝牙耳机和 Core Audio 排障步骤见 [macOS 音频排障](macos-audio-troubleshooting.md)。

**3. 启动桌面版**

桌面版功能最完整：

```bash
uv run sp.py
```

如果要指定界面语言：

```bash
uv run sp.py --lang zh
```

**4. 使用命令行**

项目 CLI 入口是 `cli.py`，支持四类任务：

```bash
uv run cli.py --task stt --name "/path/to/video.mp4"
```

常用示例：

```bash
# 视频/音频转字幕
uv run cli.py --task stt --name "./demo.mp4"

# 字幕翻译
uv run cli.py --task sts --name "./demo.srt" --target_language_code en

# 字幕配音
uv run cli.py --task tts --name "./demo.srt" --voice_role "zh-CN-YunyangNeural"

# 完整视频翻译
uv run cli.py --task vtv --name "./demo.mp4" --source_language_code zh-cn --target_language_code en --voice_role "en-US-GuyNeural"
```

查看可用渠道：

```bash
uv run cli.py --list providers
uv run cli.py --list languages
uv run cli.py --list models
```

**5. 启动 WebUI**

WebUI 需要额外安装 Gradio：

```bash
uv sync --extra webui
uv run webui.py
```

默认访问：

```text
http://127.0.0.1:7860
```

指定端口：

```bash
uv run webui.py --port 8080
```

**6. 输出位置**

默认结果一般会输出到项目下的：

```text
output/
```

运行中产生的日志在：

```text
logs/
```

推荐你先用桌面版：

```bash
uv run sp.py
```

如果只是批量处理或服务器运行，再用 `cli.py`。
