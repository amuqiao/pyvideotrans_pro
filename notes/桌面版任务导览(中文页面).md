# 桌面版任务导览（中文页面）

本文面向已经切换到中文界面的桌面客户端新用户：先建立“这个软件如何完成任务”的心智模型，再带你按场景做出成片、字幕、配音和素材加工结果。读完并按场景走一遍后，你应该能自己判断“我有什么输入、想得到什么输出、该打开哪个中文入口、哪些设置必须改、结果到哪里检查”。

## 先建立心智模型

桌面版不是一个单纯的“视频翻译表单”，而是一个围绕音视频本地加工的任务中枢。它把识别、翻译、配音、字幕、音频处理、视频合成这些能力串成主流程，也把每个能力拆成独立工具，方便你只做其中一步。

```text
你的输入
  原始视频 / 原始音频 / 已有 SRT / 纯文本 / 图片水印 / 参考音频

进入桌面端后先问 3 个问题
  1. 我要完整成片，还是只要中间素材？
  2. 我手里有没有字幕，还是需要软件先识别？
  3. 我要不要目标语种配音，还是只要目标语种字幕？

然后选择路径
  完整成片
    -> 翻译视频或音频
    -> 识别 -> 翻译 -> 可选配音 -> 字幕/音频/视频合成

  只要字幕
    -> 转录并翻译字幕
    -> 或 批量语音转字幕
    -> 或 批量翻译srt字幕

  已有字幕/音频/视频，需要加工
    -> 工具/选项(&T)
    -> 合并、转换、裁剪、混音、水印、文稿对齐

  渠道不可用或效果不对
    -> 翻译设置(&S) / TTS设置(&E) / 语音识别设置(&R) / 工具/选项(&T)
    -> 翻译渠道 / 语音识别渠道 / TTS 渠道 / 网络代理 / 高级选项
```

源码上，这个心智模型对应三层入口：

| 层级 | 中文界面入口 | 它解决什么问题 | 主要源码 |
|---|---|---|---|
| 主工作台 | `翻译视频或音频`、`转录并翻译字幕` | 把识别、翻译、配音、合成串成任务 | [主窗口](../videotrans/mainwin/main_win.py)、[启动校验](../videotrans/mainwin/_actions.py)、[模式切换](../videotrans/mainwin/_actions_base.py) |
| 独立生产工具 | `批量语音转字幕`、`批量翻译srt字幕`、`批量为字幕配音`、`字幕多角色配音` | 只做链路中的某一步 | [语音识别](../videotrans/winform/fn_recogn.py)、[字幕翻译](../videotrans/winform/fn_fanyisrt.py)、[语音合成](../videotrans/winform/fn_peiyin.py)、[多角色配音](../videotrans/winform/fn_peiyinrole.py) |
| 素材修补工具 | `音视频字幕合并`、`视频与音频合并`、`视频与字幕合并` 等 | 把素材整理成主流程需要的形态，或直接输出成品 | [菜单入口](../videotrans/ui/en.py) |

如果你需要从源码角度理解更底层的模块边界，可以先看 [项目能力拆解](项目能力拆解.md)。如果环境还没装好，先看 [环境安装](环境安装.md)。

## 桌面端完整能力地图

下面这张表不是让你背按钮，而是让你知道桌面端能力没有被拆散：主工作台负责完整生产，工具菜单负责单点加工，设置和帮助菜单负责让外部依赖可用。

| 能力区 | 中文界面入口 | 你应该怎么理解 |
|---|---|---|
| 输入 | `选择音频或视频`、`文件夹`、`导入原始语言字幕`、`输出到..` | 先把素材交给任务，不同模式决定后续怎么处理 |
| 识别 | `语音识别`、`识别模型`、`启用CUDA?`、`降噪`、`识别说话人`、`恢复标点`、`LLM重新断句` | 把音频变成可编辑、可翻译的时间轴文本 |
| 翻译 | `翻译渠道`、`目标语言`、`发送完整字幕`、`翻译术语表` | 把字幕内容换成目标语种，并尽量保持上下文 |
| 配音 | `配音渠道`、`配音角色`、`试听`、`配音语速+%`、`音量+`、`音调+` | 把目标字幕变成目标语种声音 |
| 对齐 | `配音加速+`、`视频慢速`、`删字幕间静音`、`对齐字幕声音` | 解决“字幕、声音、视频时长不一致”的问题 |
| 字幕 | `不嵌入字幕`、`嵌入硬字幕`、`嵌入软字幕`、`修改硬字幕样式` | 决定字幕是单独文件、软字幕，还是烧录到画面里 |
| 背景音 | `分离人声背景声`、`重新嵌入背景音`、`添加额外背景音频`、`背景音量` | 在替换人声时尽量保留或重新铺底噪、音乐、环境声 |
| 任务控制 | `开始执行`、`重试失败`、`清理已生成`、`仅输出mp4`、`完成后关机` | 控制批量任务的执行成本和产物数量 |
| 独立工具 | `批量语音转字幕`、`批量翻译srt字幕`、`批量为字幕配音`、`音视频字幕合并` 等 | 当你不需要完整主流程时，单独使用某一步 |
| 配置支持 | `网络代理`、`翻译设置(&S)`、`TTS设置(&E)`、`语音识别设置(&R)`、`高级选项`、`帮助/关于(&H)` | 让 API、模型、网络、FFmpeg、CUDA 这些外部依赖可用 |

## 模块心智模型

### 主工作台：把“素材”变成“成片”

主工作台的核心不是某个按钮，而是下面这条流水线。

```text
选择音频或视频
  -> 发音语言 / 目标语言
  -> 语音识别 / 识别模型
  -> 翻译渠道
  -> 可选：配音渠道 / 配音角色 / 试听
  -> 可选：修改硬字幕样式 / 添加额外背景音频 / 对齐控制
  -> 开始执行
  -> 任务进度列表
  -> 翻译结果保存到:
```

`翻译视频或音频` 能做完整音视频翻译。它可以只生成字幕，也可以继续生成配音并合成视频。`转录并翻译字幕` 更轻，只处理“识别字幕、翻译字幕、输出字幕”，不承担完整配音合成。

### 识别模块：把声音变成时间轴文本

```text
video/audio
  -> 语音识别
  -> 识别模型
  -> 发音语言
  -> 可选：启用CUDA? / 降噪 / 识别说话人 / 恢复标点 / LLM重新断句
  -> SRT / TXT
```

识别模块在主流程和独立 `批量语音转字幕` 工具里都会用到。主流程用它继续往下翻译和配音；独立工具适合只想拿字幕文件。

### 翻译模块：把原文字幕变成目标语言字幕

```text
source SRT
  -> 翻译渠道
  -> 目标语言
  -> 可选：发送完整字幕 / 翻译术语表
  -> 目标语种 SRT / TXT
```

翻译可以接主流程的识别结果，也可以通过 `批量翻译srt字幕` 工具单独处理已有 SRT。

### 配音模块：把目标语言字幕变成音频

```text
target text / target SRT
  -> 配音渠道
  -> 字幕语言 / 目标语言
  -> 配音角色
  -> 配音语速+% / 音量+ / 音调+
  -> 可选：配音加速+ / 删字幕间静音
  -> 配音音频
```

如果你在主工作台把 `配音角色` 选成 `No`，就不会进入配音链路。只有选择了有效 `配音渠道` 和 `配音角色`，才会生成目标语种配音。

### 合成模块：把视频、音频、字幕封装成结果

```text
原视频
  + 目标语种音频
  + 目标语种字幕
  + 可选背景音
  + 可选字幕样式
  -> 目标 MP4
```

这一步会受到字幕类型、音频对齐、视频自动变速、是否保留背景音、是否只输出 MP4 等选项影响。

## 场景 1：做出第一条目标语种配音 MP4

这个场景回答最核心的问题：是否支持“单个原始 MP4 + 目标语种 -> 目标语种配音 MP4”。结论是支持，入口是 `翻译视频或音频`。

### 你会得到什么

```text
输入：一个原始 MP4
输出：目标语种字幕文件、目标语种配音音频、合成后的目标语种 MP4
```

如果只想测试流程，建议先用 1 到 3 分钟的视频。这样你能更快看见每一步的结果，也更容易判断识别、翻译、配音哪里需要调整。

### 操作路径

先按这个页面动线找位置：

```text
工具栏
  -> 翻译视频或音频

左侧主操作面板
  顶部输入行
    -> 选择音频或视频
    -> 输出到..

  识别行
    -> 语音识别
    -> 识别模型

  翻译行
    -> 翻译渠道
    -> 发音语言
    -> 目标语言

  配音行
    -> 配音渠道
    -> 配音角色
    -> 试听

  对齐行
    -> 配音加速+
    -> 视频慢速
    -> 不嵌入字幕 / 嵌入硬字幕 / 嵌入硬字幕(双) / 嵌入软字幕 / 嵌入软字幕(双)

  底部任务区
    -> 启用CUDA?
    -> 开始执行
```

1. 在工具栏选择 `翻译视频或音频`。
2. 点 `选择音频或视频` 选择原始 MP4。第一次建议只选一个；如果要选文件夹，先勾选旁边的 `文件夹`。
3. 点 `输出到..` 选择输出目录。
4. 在 `发音语言` 设置源语言。例如中文视频选中文，英文视频选英文。
5. 在 `目标语言` 设置目标语言。例如要做英文配音，就选英文。
6. 在 `语音识别` 和 `识别模型` 选择识别渠道和模型。默认小模型速度快，大模型效果更好但更慢。
7. 在 `翻译渠道` 选择翻译渠道。免费渠道适合测试，AI 或商业渠道适合质量更稳定的成片。
8. 在 `配音渠道` 和 `配音角色` 选择配音渠道和音色。`配音角色` 不能是 `No`，否则不会配音。
9. 点 `试听`，确认音色、语速、音量、音调大致合适。
10. 在对齐行选择字幕类型。需要成片显示字幕时选硬字幕或软字幕；只要音频成片时可以选 `不嵌入字幕`。
11. 点 `开始执行`，等待任务进度列表完成。
12. 看底部 `翻译结果保存到:` 的输出目录，检查目标 MP4、SRT、音频文件。

### 这条流水线内部发生了什么

```text
MP4
  -> 提取音频
  -> ASR 识别为原语言 SRT
  -> 翻译为目标语言 SRT
  -> TTS 合成为目标语言音频
  -> 对齐音频和字幕
  -> 合并视频、音频、字幕
  -> 输出目标语种 MP4
```

### 第一次建议只改这些设置

| 设置 | 新手建议 | 为什么 |
|---|---|---|
| 发音语言 | 明确选择，不要猜 | 识别模型会受语言影响 |
| 目标语言 | 必选 | 翻译、字幕、配音都依赖它 |
| 识别模型 | 先用默认或中等模型 | 先跑通，再追求效果 |
| 翻译渠道 | 先选你已经配置好的渠道 | 避免 API key 问题打断流程 |
| 配音角色 | 必须选有效音色 | `No` 表示不配音 |
| 输出目录 | 选一个空目录或易找目录 | 方便检查生成文件 |

### 成片不理想时先改哪里

```text
字幕听不准
  -> 识别模型 换更大的识别模型
  -> 设置更多参数... -> 降噪
  -> 检查 发音语言
  -> 设置更多参数... -> 识别说话人 / 恢复标点

翻译不自然
  -> 翻译渠道 换翻译渠道
  -> 翻译术语表 固定术语
  -> 对 AI 渠道尝试 发送完整字幕

配音太快或太慢
  -> 设置更多参数... -> 配音语速+%
  -> 对齐行 -> 配音加速+
  -> 删字幕间静音

配音和画面时长冲突
  -> 对齐行 -> 视频慢速
  -> 或在 音视频字幕合并 里选择截断、自动加速、视频末尾定格
```

## 场景 6：独立语音识别

当你只想从音视频中拿到文字或字幕，不想翻译、不想配音，用 `批量语音转字幕`。

### 你会得到什么

```text
输入：一个或多个音频/视频
输出：SRT、TXT 或其他界面支持的字幕文本格式
```

### 操作路径

页面动线：

```text
工具栏
  -> 批量语音转字幕

语音识别窗口
  输入区
    -> 选择音视频文件 / 拖拽音视频文件

  识别设置
    -> 原始语言
    -> 语音识别
    -> 选择使用的模型
    -> 输出字幕格式
    -> 启用CUDA?

  增强设置
    -> 降噪
    -> 恢复标点
    -> 识别说话人
    -> 说话人数
    -> 插入说话人标识
    -> 默认断句 / LLM重新断句

  操作区
    -> 开始执行
    -> 停止
    -> 打开输出目录
```

1. 在工具栏选择 `批量语音转字幕`。
2. 导入音频或视频。
3. 在 `原始语言` 选择发音语言。
4. 在 `语音识别` 和 `选择使用的模型` 选择识别渠道和模型。
5. 按需开启 `启用CUDA?`。
6. 按需开启 `降噪`、标点修复、`识别说话人`、`插入说话人标识`、`LLM重新断句`。

8. 点击 `开始执行`。
9. 打开输出目录检查识别结果。

### 增强选项怎么理解

| 选项 | 心智模型 | 适合场景 |
|---|---|---|
| 启用CUDA? | 用 GPU 加速识别 | 本机 NVIDIA 显卡和驱动可用时 |
| 降噪 | 先清理背景噪声再识别 | 录音环境嘈杂 |
| 识别说话人 | 尝试区分不同说话人 | 访谈、多人对话 |
| 恢复标点 | 让字幕更像自然句子 | 识别结果没有标点或断句差 |
| LLM重新断句 | 用 LLM 改善长句切分 | 字幕行太长、阅读困难 |

## 场景 7：把已有素材合成最终视频

如果你已经有视频、配音音频、字幕，或者想在主流程外手动合成成片，使用 `音视频字幕合并`。

### 你会得到什么

```text
输入：视频必选，音频和 SRT 至少选一个
输出：新的 MP4
```

### 操作路径

页面动线：

```text
工具栏
  -> 音视频字幕合并

音视频字幕合并窗口
  窗口标题
    -> 视频、音频、字幕三者合并

  必选输入
    -> 视频文件 / 选择视频

  可选输入，至少选一个
    -> 音频文件 / 选择音频文件
    -> 字幕文件/srt / 选择srt字幕文件

  音频策略
    -> 保留视频中原声音
    -> 音频时长大于视频时
    -> 自动加速 / 视频末尾定格

  字幕策略
    -> 默认按硬字幕处理
    -> 嵌入软字幕
    -> 软字幕语言
    -> 字幕单行字符数
    -> 保留原换行
    -> 修改硬字幕样式

  操作区
    -> 开始执行
    -> 打开结果目录
```

1. 在工具栏选择 `音视频字幕合并`。
2. 通过 `视频文件 / 选择视频` 选择视频。
3. 通过 `音频文件 / 选择音频文件` 选择音频，或通过 `字幕文件/srt / 选择srt字幕文件` 选择字幕，或两者都选。
4. 如果选择音频，决定是否保留原视频声音。
5. 如果新音频比视频长，选择处理策略：截断音频、自动加速音频、视频末尾定格。
6. 如果选择 SRT，默认按硬字幕处理；如果想让字幕作为可开关字幕轨封装，勾选 `嵌入软字幕`。
7. 使用软字幕时设置 `软字幕语言`；使用硬字幕时设置最大行宽、是否保留换行，并按需打开 `修改硬字幕样式`。
8. 确认音频和字幕策略后，点击 `开始执行`。
9. 打开输出目录检查 MP4。

### 三种合成方式的区别

| 你选择的素材 | 会发生什么 |
|---|---|
| 视频 + 音频 | 替换或混合视频声音 |
| 视频 + SRT | 把字幕封装或烧录进视频 |
| 视频 + 音频 + SRT | 同时处理声音和字幕 |

硬字幕会烧录在画面里，播放器都能看到，但以后不容易关闭。软字幕会作为字幕轨封装到 MP4 里，播放器支持时可以开关。

## 场景 8：素材工具箱

```text
  -> 工具/选项(&T) -> 实时语音转文字
  -> 实时识别
  -> 文本片段
  -> 导出 TXT
```

源码入口：[实时转写](../videotrans/component/realtime_stt.py)。

## 场景 9：配置、排错与维护

桌面端很多问题不是“流程不会跑”，而是某个外部渠道没有配置、网络不可达、模型不可用、字幕样式不符合成片要求。

### 9.1 渠道配置

把渠道理解成三类插槽：

```text
识别渠道 ASR
  用来把声音变字幕

翻译渠道 Translation
  用来把原文字幕变目标语种字幕

配音渠道 TTS
  用来把字幕或文本变声音
```

主窗口会根据你选择的渠道检查语言、模型、API 配置是否可用。需要 API key、本地服务地址或模型路径的渠道，先到 `翻译设置(&S)`、`TTS设置(&E)`、`语音识别设置(&R)` 菜单对应项里填写。

| 类型 | 典型配置入口 |
|---|---|
| 翻译 | `翻译设置(&S)`：`百度翻译`、`阿里机器翻译`、`腾讯翻译设置`、`DeepL Key`、`DeepLX Api`、`OpenAI API 及兼容AI`、`AzureGPT 翻译`、`DeepSeek`、`OpenRouter.ai`、`本地大模型(兼容OpenAI)`、`LibreTranslate API`、`自定义翻译API` 等 |
| TTS | `TTS设置(&E)`：`OpenAI TTS`、`AzureAI 配音`、`ElevenLabs.io`、`GPT-SoVITS TTS`、`CosyVoice TTS`、`Fish TTS`、`F5/Index/VoxCPM/SparK/Dia/Confucius`、`clone-voice`、`设置参考音频`、`自定义TTS API` 等 |
| ASR | `语音识别设置(&R)`：`OpenAI语音识别及兼容API`、`自定义语音识别API`、`STT语音识别API`、`WhisperX-API`、`Deepgram.com语音识别`、`Faster_Whisper_XXL.exe`、`Whisper.cpp`、`VolcEngine STT` 等 |

不要把“网络代理”和“某个 API 地址”混在一起。代理是全局网络出口，API 地址应该填在对应渠道配置里。

### 9.2 字幕样式

需要硬字幕或视频合成时，打开 `修改硬字幕样式`。它可以调整字体、字号、颜色、描边、阴影、边距、位置，并提供预览。

```text
目标字幕
  -> ASS 样式
  -> 硬字幕烧录
  -> 成片画面
```

源码入口：[字幕样式](../videotrans/component/set_ass.py)。

### 9.3 网络代理

如果模型下载、翻译 API、TTS API 访问慢或失败，先确认是否需要代理。代理入口有两个：主窗口 `网络代理` 输入框，或 `工具/选项(&T) -> 设置网络代理`。代理格式通常类似 `http://127.0.0.1:端口` 或 socks 代理。

```text
需要代理的情况
  -> 外部 API 访问失败
  -> Hugging Face 模型下载失败
  -> Google 翻译等网络服务不可达

不该填在代理里的内容
  -> ChatGPT API base url
  -> 自定义识别接口地址
  -> 自定义 TTS 接口地址
```

源码入口：[代理设置](../videotrans/component/set_proxy.py)。

### 9.4 高级选项

`工具/选项(&T) -> 高级选项` 窗口保存更底层的全局设置，例如模型列表、Hugging Face token、视频编码、输出目录、语言选项等。它适合在你已经知道要调整什么时使用。

```text
普通任务效果问题
  -> 优先调整主窗口选项

模型列表、编码、token、全局路径、界面语言问题
  -> 再打开 高级选项
```

源码入口：[高级设置](../videotrans/winform/setini.py)。

### 9.5 清理缓存和重试失败

主流程会生成临时音频、字幕、缓存和任务中间文件。出现中断、输出异常、临时文件过多时，可以用 `工具/选项(&T) -> 清空缓存`。批量任务里如果部分失败，优先使用主窗口底部的 `重试失败`，不要整批从头跑。

### 9.6 帮助菜单

帮助菜单不是生产链路，但它覆盖新用户常见外部问题：

| 入口 | 解决什么 |

| `遇到问题?在线提问` | 在线提问和社区帮助 |

| `Github Repository`、`GitHub Issues` | 源码、反馈和问题跟踪 |
| `软件许可与服务协议`、`关于 / 联系 / 捐赠` | 使用边界和项目信息 |

## 主工作台高级选项怎么选

这些选项不需要第一次全部打开。你可以按问题来选。

| 问题 | 优先看这些选项 |
|---|---|
| 识别慢 | `识别模型`、`启用CUDA?`、`语音识别` |
| 识别错字多 | `发音语言`、`识别模型`、`降噪`、`恢复标点`、`LLM重新断句` |
| 多人说话混在一起 | `识别说话人`、说话人数 |
| 翻译术语不稳定 | `翻译术语表`、`发送完整字幕`、`翻译渠道` |
| 配音时长对不上字幕 | `配音加速+`、`删字幕间静音`、`配音语速+%` |
| 配音比视频长 | `视频慢速`、`音视频字幕合并` 里的音频处理策略 |
| 想保留原背景音乐 | `分离人声背景声`、`重新嵌入背景音`、`添加额外背景音频`、`背景音量` |
| 字幕太长或样式不好看 | `不嵌入字幕` / `嵌入硬字幕` / `嵌入软字幕`、`修改硬字幕样式`、`字幕单行字符数` |
| 只想要最终 MP4 | `仅输出mp4` |
| 跑完自动关机 | `完成后关机` |

## 完整练习路线

如果你想按教程把桌面端功能真正跑熟，可以按这个顺序做：

```text
第 1 轮：跑通主线
  翻译视频或音频
  -> 单个 MP4 做目标语种配音 MP4

第 2 轮：拆开主线
  批量语音转字幕
  -> 批量翻译srt字幕
  -> 批量为字幕配音
  -> 音视频字幕合并

第 3 轮：处理已有素材
  批转换字幕格式
  -> 合并两个字幕
  -> 视频与字幕合并
  -> 视频与音频合并

第 4 轮：处理复杂素材
  人声/背景音分离
  -> 批量从视频中分离音频
  -> 文稿匹配与打轴
  -> 按字幕剪辑视频
  -> 批量视频添加水印

第 5 轮：处理生产问题
  网络代理 / 设置网络代理
  -> 翻译设置(&S) / TTS设置(&E) / 语音识别设置(&R)
  -> 修改硬字幕样式
  -> 高级选项
  -> 清空缓存 / 重试失败
```

完成这 5 轮后，你不需要记住每个按钮，只需要记住这个判断方式：

```text
要成片，走 翻译视频或音频 或 音视频字幕合并。
要中间素材，走 批量语音转字幕、批量翻译srt字幕、批量为字幕配音。
要修素材，走 工具/选项(&T) 菜单。
要修渠道和环境，走 翻译设置(&S) / TTS设置(&E) / 语音识别设置(&R) / 帮助/关于(&H)。
```
