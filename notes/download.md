这些是本次任务生成的中间文件和输出文件，WebUI 把它们列出来方便下载。

| 文件 | 含义 |
|---|---|
| `vocal.wav` | 从原视频里分离出来的人声轨。你开启了“分离人声”，所以会生成它。 |
| `instrument.wav` | 从原视频里分离出来的背景音/伴奏轨。后续嵌入背景音会用它。 |
| `zh-cn.srt` | 原始中文识别字幕，也就是 faster-whisper 识别出来的字幕文件。 |
| `zh-cn.m4a` | 原始中文音频轨，通常是从视频中提取/处理后的源语言音频。 |
| `en.src` | 翻译后的英文字幕/文本中间文件，供后续配音或合成使用。 |
| `en.m4a` | 生成的英文配音音频，也就是 Qwen3-TTS 配出来的目标语言音频。 |

简单理解流程：

```text
原视频
  -> 拆出 zh-cn.m4a
  -> 分离 vocal.wav / instrument.wav
  -> 识别出 zh-cn.srt
  -> 翻译出 en.src
  -> 配音生成 en.m4a
```

如果你最终要看成片，通常还会有一个合成后的视频文件，例如 `.mp4`。你现在看到这些更像是任务过程中产出的音频、字幕和中间结果。
