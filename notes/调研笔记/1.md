你要的文档应回答：

1. **这个项目到底能做什么**
   不是泛泛说“视频翻译工具”，而是拆成具体能力：
   - 语音识别能力
   - 字幕翻译能力
   - TTS 配音能力
   - 视频/音频拆分能力
   - 人声/背景声分离能力
   - 音频对齐能力
   - 字幕嵌入能力
   - MP4 合成能力
   - CLI / GUI / WebUI 各自能调哪些能力

2. **单模块能力**
   每个模块单独能完成什么：
   ```text
   输入是什么
   输出是什么
   调用入口在哪里
   核心源码在哪里
   使用什么技术栈
   成功后产物是什么
   失败点在哪里
   ```

3. **串联能力**
   例如 `vtv` 这种完整链路：
   ```text
   MP4
     -> prepare
     -> recogn
     -> diariz
     -> trans
     -> dubbing
     -> align
     -> recogn2pass
     -> assembling
     -> task_done
     -> 输出 MP4 / SRT / 音频
   ```
   每一步都要说明：
   - 由哪个类/函数执行
   - 消费哪些中间文件或配置
   - 生成哪些中间产物
   - 下一步如何接上

4. **分支能力**
   不是所有流程都固定跑全链路，要拆出条件分支：
   - 是否配音：`voice_role = No` 时不走配音
   - 是否分离背景音：`is_separate`
   - 是否二次识别：`recogn2pass`
   - 是否嵌入字幕：`subtitle_type`
   - 是否只做 STT / STS / TTS / VTV
   - CLI、GUI、WebUI 能力边界是否一致

5. **文字可视化拆解**
   文档里要用清晰的文字图、表格、流程图，比如：
   ```text
   输入 MP4
     |

                    v

                    |

                    v

   ```
