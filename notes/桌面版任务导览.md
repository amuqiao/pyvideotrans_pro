# 桌面版任务导览

本文面向第一次打开桌面客户端的新用户：读完并按场景做一遍后，你应该能自己判断“我现在有什么素材、想得到什么成品、该打开哪个功能、哪些设置必须改、输出在哪里检查”。

## 先建立心智模型

桌面版不是一个单纯的“视频翻译表单”，而是一个围绕音视频本地加工的任务中枢。它把识别、翻译、配音、字幕、音频处理、视频合成这些能力串成主流程，也把每个能力拆成独立工具，方便你只做其中一步。

```text
你的输入
  原始视频 / 原始音频 / 已有 SRT / 纯文本 / 图片水印 / 参考音频

进入桌面端后先问 3 个问题
  1. 我要完整成片，还是只要中间素材？
  2. 我手里有没有字幕，还是需要软件先识别？
  3. 我要不要目标语种配音，还是只要目标语种字幕？

然后选择路径
  完整成片
    -> 标准功能模式
    -> 识别 -> 翻译 -> 配音可选 -> 字幕/音频/视频合成

  只要字幕
    -> 提取 SRT 并翻译
    -> 或独立语音识别
    -> 或独立字幕翻译

  已有字幕/音频/视频，需要加工
    -> 工具菜单
    -> 合并、转换、裁剪、混音、水印、文稿对齐

  渠道不可用或效果不对
    -> 设置菜单
    -> 翻译渠道 / 语音识别渠道 / TTS 渠道 / 代理 / 高级选项
```

源码上，这个心智模型对应三层入口：

| 层级 | 你看到的入口 | 它解决什么问题 | 主要源码 |
|---|---|---|---|
| 主工作台 | 标准功能模式、提取 SRT 并翻译 | 把识别、翻译、配音、合成串成任务 | [主窗口](../videotrans/mainwin/main_win.py)、[启动校验](../videotrans/mainwin/_actions.py)、[模式切换](../videotrans/mainwin/_actions_base.py) |
| 独立生产工具 | 语音识别、字幕翻译、语音合成、多角色 SRT 配音 | 只做链路中的某一步 | [语音识别](../videotrans/winform/fn_recogn.py)、[字幕翻译](../videotrans/winform/fn_fanyisrt.py)、[语音合成](../videotrans/winform/fn_peiyin.py)、[多角色配音](../videotrans/winform/fn_peiyinrole.py) |
| 素材修补工具 | 合并、转换、裁剪、水印、分离、实时转写 | 把素材整理成主流程需要的形态，或直接输出成品 | [菜单入口](../videotrans/ui/en.py) |

如果你需要从源码角度理解更底层的模块边界，可以先看 [项目能力拆解](项目能力拆解.md)。如果环境还没装好，先看 [环境安装](环境安装.md)。

## 快速选择路径

先不要研究所有按钮。用下面这张图决定从哪里开始。

```text
我有一个 MP4，想变成目标语种配音 MP4
  -> 场景 1：做出第一条目标语种配音视频

我有一个 MP4，只想提取字幕或翻译字幕
  -> 场景 2：提取 SRT 并翻译

我有 SRT，想翻译成另一种语言
  -> 场景 3：批量翻译字幕

我有 SRT 或一段文本，想生成配音音频
  -> 场景 4：从文本或 SRT 合成语音

我有多角色 SRT，想让不同台词用不同声音
  -> 场景 5：多角色 SRT 配音

我只想把音视频识别成字幕
  -> 场景 6：独立语音识别

我有视频、音频、字幕，想手动合成一个 MP4
  -> 场景 7：把素材合成最终视频

我有一堆素材要批量修补、转换、剪辑
  -> 场景 8：素材工具箱

我遇到渠道、模型、代理、CUDA、字幕样式问题
  -> 场景 9：配置、排错与维护
```

## 桌面端完整能力地图

下面这张表不是让你背按钮，而是让你知道桌面端能力没有被拆散：主工作台负责完整生产，工具菜单负责单点加工，设置和帮助菜单负责让外部依赖可用。

| 能力区 | 覆盖的功能 | 你应该怎么理解 |
|---|---|---|
| 输入 | 选择单个文件、批量文件、文件夹、导入已有字幕、选择输出目录 | 先把素材交给任务，不同模式决定后续怎么处理 |
| 识别 | 识别渠道、模型、源语言、CUDA、降噪、说话人分离、说话人数、标点修复、二次断句 | 把音频变成可编辑、可翻译的时间轴文本 |
| 翻译 | 翻译渠道、模型、目标语言、术语表、完整 SRT 发送给 AI | 把字幕内容换成目标语种，并尽量保持上下文 |
| 配音 | TTS 渠道、音色、试听、语速、音量、音调、克隆或参考音频相关配置 | 把目标字幕变成目标语种声音 |
| 对齐 | 配音自动适配、视频自动变速、去除中间静音、字幕音频对齐 | 解决“字幕、声音、视频时长不一致”的问题 |
| 字幕 | 字幕类型、输出 SRT、字幕样式 | 决定字幕是单独文件、软字幕，还是烧录到画面里 |
| 背景音 | 人声伴奏分离、嵌入背景音、背景音乐、循环背景音、背景音量 | 在替换人声时尽量保留或重新铺底噪、音乐、环境声 |
| 任务控制 | 开始、停止、失败重试、清理缓存、只输出 MP4、完成后关机 | 控制批量任务的执行成本和产物数量 |
| 独立工具 | 识别、翻译、配音、多角色配音、合并、转换、裁剪、水印、实时转写 | 当你不需要完整主流程时，单独使用某一步 |
| 配置支持 | 代理、翻译配置、识别配置、TTS 配置、选项、帮助文档 | 让 API、模型、网络、FFmpeg、CUDA 这些外部依赖可用 |

## 模块心智模型

### 主工作台：把“素材”变成“成片”

主工作台的核心不是某个按钮，而是下面这条流水线。

```text
选择文件
  -> 设置源语言和目标语言
  -> 选择识别渠道和模型
  -> 选择翻译渠道
  -> 可选：选择 TTS 渠道和音色
  -> 可选：设置字幕样式、背景音、对齐策略
  -> 开始
  -> 进度条跟踪每个任务
  -> 检查输出目录
```

标准功能模式能做完整音视频翻译。它可以只生成字幕，也可以继续生成配音并合成视频。提取 SRT 并翻译模式更轻，只处理“识别字幕、翻译字幕、输出字幕”，不承担完整配音合成。

### 识别模块：把声音变成时间轴文本

```text
视频/音频
  -> 识别渠道
  -> 模型
  -> 源语言
  -> 可选：CUDA、降噪、说话人分离、标点修复、二次断句
  -> SRT / TXT
```

识别模块在主流程和独立“语音识别文本”工具里都会用到。主流程用它继续往下翻译和配音；独立工具适合只想拿字幕文件。

### 翻译模块：把原文字幕变成目标语言字幕

```text
SRT 原文
  -> 翻译渠道
  -> 目标语种
  -> 可选：术语表、把完整 SRT 发给 AI
  -> 目标语种 SRT / TXT
```

翻译可以接主流程的识别结果，也可以通过“文本或 SRT 翻译”工具单独处理已有 SRT。

### 配音模块：把目标语言字幕变成音频

```text
目标语种文本 / 目标语种 SRT
  -> TTS 渠道
  -> 语言
  -> 音色
  -> 语速 / 音量 / 音调
  -> 可选：自动适配字幕时长、去除静音
  -> 配音音频
```

如果你在主工作台把音色选成 `No`，就不会进入配音链路。只有选择了有效 TTS 渠道和音色，才会生成目标语种配音。

### 合成模块：把视频、音频、字幕封装成结果

```text
原视频
  + 目标语种音频
  + 目标语种字幕
  + 可选背景音
  + 可选字幕样式
  -> 目标 MP4
```

这一步会受到字幕类型、音频对齐、视频自动变速、是否保留背景音、是否只输出 MP4 等选项影响。

## 场景 1：做出第一条目标语种配音 MP4

这个场景回答你最关心的问题：是否支持“单个原始 MP4 + 目标语种 -> 目标语种配音 MP4”。结论是支持，入口是标准功能模式。

### 你会得到什么

```text
输入：一个原始 MP4
输出：目标语种字幕文件、目标语种配音音频、合成后的目标语种 MP4
```

如果只想测试流程，建议先用 1 到 3 分钟的视频。这样你能更快看见每一步的结果，也更容易判断识别、翻译、配音哪里需要调整。

### 操作路径

1. 在工具栏选择“标准功能模式”。
2. 选择原始视频文件，单个 MP4 或文件夹都可以。第一次建议只选一个。
3. 设置源语言。例如中文视频选中文，英文视频选英文。
4. 设置目标语言。例如要做英文配音，就选英文。
5. 选择识别渠道和模型。默认小模型速度快，大模型效果更好但更慢。
6. 选择翻译渠道。免费渠道适合测试，AI 或商业渠道适合质量更稳定的成片。
7. 选择 TTS 渠道和音色。音色不能是 `No`，否则不会配音。
8. 点击试听，确认音色、语速、音量、音调大致合适。
9. 选择字幕类型。需要成片显示字幕时选硬字幕或软字幕；只要音频成片时可以不嵌字幕。
10. 点击开始，等待进度条完成。
11. 打开输出目录，检查目标 MP4、SRT、音频文件。

### 这条流水线内部发生了什么

```text
MP4
  -> 提取音频
  -> ASR 识别为原语言 SRT
  -> 翻译为目标语言 SRT
  -> TTS 合成为目标语言音频
  -> 对齐音频和字幕
  -> 合并视频、音频、字幕
  -> 输出目标语种 MP4
```

### 第一次建议只改这些设置

| 设置 | 新手建议 | 为什么 |
|---|---|---|
| 源语言 | 明确选择，不要猜 | 识别模型会受语言影响 |
| 目标语言 | 必选 | 翻译、字幕、配音都依赖它 |
| 识别模型 | 先用默认或中等模型 | 先跑通，再追求效果 |
| 翻译渠道 | 先选你已经配置好的渠道 | 避免 API key 问题打断流程 |
| TTS 音色 | 必须选有效音色 | `No` 表示不配音 |
| 输出目录 | 选一个空目录或易找目录 | 方便检查生成文件 |

### 成片不理想时先改哪里

```text
字幕听不准
  -> 换更大的识别模型
  -> 开启降噪
  -> 检查源语言
  -> 必要时开启说话人分离或标点修复

翻译不自然
  -> 换翻译渠道
  -> 打开术语表
  -> 对 AI 渠道尝试“发送完整 SRT”

配音太快或太慢
  -> 调整语速
  -> 开启配音自动适配
  -> 开启去除中间静音

配音和画面时长冲突
  -> 开启视频自动变速
  -> 或在合成工具里选择音频截断、音频加速、视频定格
```

## 场景 2：提取 SRT 并翻译

当你只需要字幕文件，不需要配音视频，用“提取 SRT 并翻译”模式更直接。

### 你会得到什么

```text
输入：视频或音频
输出：原语言 SRT、目标语言 SRT
不输出：目标语种配音 MP4
```

### 操作路径

1. 在工具栏选择“提取 SRT 并翻译”。
2. 选择视频或音频文件。
3. 设置源语言。
4. 如果只提取原文字幕，目标语言可以按界面提示处理；如果要翻译，选择目标语言和翻译渠道。
5. 选择识别渠道和模型。
6. 按需打开降噪、标点修复、说话人分离、二次断句。
7. 点击开始提取和翻译。
8. 在输出目录检查 SRT。

### 适合这个模式的任务

| 目标 | 是否适合 |
|---|---|
| 给视频提取原文字幕 | 适合 |
| 把视频字幕翻译成另一种语言 | 适合 |
| 批量处理多个视频的字幕 | 适合 |
| 做目标语种配音 MP4 | 不适合，改用标准功能模式 |
| 只处理已有 SRT | 不适合，改用“文本或 SRT 翻译” |

## 场景 3：批量翻译已有 SRT

如果你已经有 SRT 文件，不需要再识别视频，直接用“文本或 SRT 翻译”。

### 你会得到什么

```text
输入：一个或多个 .srt 文件
输出：翻译后的字幕文件
```

### 操作路径

1. 打开“文本或 SRT 翻译”。
2. 导入一个或多个 SRT。
3. 选择源语言和目标语言。
4. 选择翻译渠道。
5. 按需选择输出格式。
6. 按需开启“发送完整 SRT 给 AI”。这适合需要上下文一致性的 AI 翻译。
7. 按需打开术语表，固定人名、产品名、专业词。
8. 点击开始。
9. 单个文件时可以在窗口内查看和导出结果；多个文件时到输出目录检查。

### 什么时候用术语表

```text
人名、品牌名、专业词经常被翻错
  -> 使用术语表

上下文代词或前后句不连贯
  -> 对 AI 渠道开启完整 SRT 输入

只是快速粗翻
  -> 不必打开这些增强选项
```

## 场景 4：从文本或 SRT 合成语音

“从文本到语音”适合独立生成配音音频，不需要视频参与。

### 你会得到什么

```text
输入：纯文本、TXT 或 SRT
输出：音频文件，或按 SRT 时间轴生成的配音文件
```

### 操作路径

1. 打开“从文本到语音”。
2. 粘贴文本，或导入 TXT/SRT。
3. 选择语言。
4. 选择 TTS 渠道。
5. 选择音色。
6. 点击试听，确认声音可用。
7. 调整语速、音量、音调。
8. 如果输入是 SRT，按需开启自动适配字幕时长。
9. 点击开始合成。
10. 打开输出目录检查音频。

### 输入不同，结果也不同

| 输入 | 适合做什么 |
|---|---|
| 普通文本 | 生成一段连续朗读音频 |
| TXT 文件 | 批量或长文本朗读 |
| SRT 文件 | 按字幕时间轴生成配音 |

如果 TTS 渠道需要 API key 或本地模型，先到设置菜单配置对应渠道。音色列表会随着 TTS 渠道和语言变化。

## 场景 5：多角色 SRT 配音

当一个 SRT 里有多个角色，希望不同台词使用不同声音，使用“多角色 SRT 配音”。

### 你会得到什么

```text
输入：一个 SRT
输出：按字幕行和角色分配生成的配音音频
```

### 操作路径

1. 打开“多角色 SRT 配音”。
2. 导入 SRT。
3. 选择默认语言、TTS 渠道和默认音色。
4. 在角色分配区为字幕行指定不同音色。
5. 对未单独指定的台词，使用默认音色。
6. 按需调整语速、音量、音调和自动适配。
7. 点击开始。
8. 打开输出目录检查配音文件。

### 什么时候不需要它

```text
整条视频只需要一个旁白声音
  -> 用标准功能模式或普通语音合成

已有多角色 SRT，且需要不同声音
  -> 用多角色 SRT 配音
```

## 场景 6：独立语音识别

当你只想从音视频中拿到文字或字幕，不想翻译、不想配音，用“语音识别文本”。

### 你会得到什么

```text
输入：一个或多个音频/视频
输出：SRT、TXT 或其他界面支持的字幕文本格式
```

### 操作路径

1. 打开“语音识别文本”。
2. 导入音频或视频。
3. 选择发音语言。
4. 选择识别渠道和模型。
5. 按需开启 CUDA。
6. 按需开启降噪、标点修复、说话人分离、角色标记、二次断句。
7. 选择输出格式。
8. 点击开始。
9. 打开输出目录检查识别结果。

### 增强选项怎么理解

| 选项 | 心智模型 | 适合场景 |
|---|---|---|
| CUDA | 用 GPU 加速识别 | 本机显卡和驱动可用时 |
| 降噪 | 先清理背景噪声再识别 | 录音环境嘈杂 |
| 说话人分离 | 尝试区分不同说话人 | 访谈、多人对话 |
| 标点修复 | 让字幕更像自然句子 | 识别结果没有标点或断句差 |
| 二次断句 | 用 LLM 改善长句切分 | 字幕行太长、阅读困难 |

## 场景 7：把已有素材合成最终视频

如果你已经有视频、配音音频、字幕，或者想在主流程外手动合成成片，使用“视频字幕合并”。

### 你会得到什么

```text
输入：视频必选，音频和 SRT 至少选一个
输出：新的 MP4
```

### 操作路径

1. 打开“视频字幕合并”。
2. 选择视频。
3. 选择音频，或选择 SRT，或两者都选。
4. 如果选择音频，决定是否保留原视频声音。
5. 如果新音频比视频长，选择处理策略：截断音频、加速音频、定格视频。
6. 如果选择 SRT，决定硬字幕还是软字幕。
7. 设置字幕语言、最大行宽、是否保留原换行。
8. 需要硬字幕时，可打开字幕样式设置。
9. 点击开始。
10. 打开输出目录检查 MP4。

### 三种合成方式的区别

| 你选择的素材 | 会发生什么 |
|---|---|
| 视频 + 音频 | 替换或混合视频声音 |
| 视频 + SRT | 把字幕封装或烧录进视频 |
| 视频 + 音频 + SRT | 同时处理声音和字幕 |

硬字幕会烧录在画面里，播放器都能看到，但以后不容易关闭。软字幕会作为字幕轨封装到 MP4 里，播放器支持时可以开关。

## 场景 8：素材工具箱

这一组工具不一定属于完整翻译链路，但它们能解决真实工作中最常见的素材问题。

### 8.1 批量视频和音频一对一合并

```text
文件夹
  video1.mp4
  video1.wav
  video2.mp4
  video2.wav
  -> 批量视频/音频合并
  -> video1.mp4、video2.mp4 成品
```

使用“批量视频/音频合并”。它按同名规则匹配视频和音频。可选择是否保留原声，以及当音频比视频长时截断或加速音频。

源码入口：[批量视频音频合并](../videotrans/winform/fn_videoandaudio.py)。

### 8.2 批量视频和 SRT 一对一合并

```text
文件夹
  lesson1.mp4
  lesson1.srt
  lesson2.mp4
  lesson2.srt
  -> 批量视频 SRT 合并
  -> 带字幕视频
```

使用“批量视频 SRT 合并”。它同样按文件名匹配，可选择硬字幕或软字幕，能设置字幕语言、行宽和字幕样式。

源码入口：[批量视频字幕合并](../videotrans/winform/fn_videoandsrt.py)。

### 8.3 音视频格式转换

当素材格式不被某个工具接受，先用“批量音频/视频转换”转换格式。

```text
mp3 / m4a / wav / mp4 / mkv ...
  -> 选择目标格式
  -> 输出到 formatcover
```

源码入口：[音视频格式转换](../videotrans/winform/fn_formatcover.py)。

### 8.4 字幕格式转换

当你拿到的是 `.ass`、`.vtt`，但后续工具需要 `.srt` 或 `.txt`，使用“字幕格式转换”。

```text
srt / ass / vtt
  -> srt / ass / vtt / txt
```

转换成 TXT 时，会抽取字幕文本。源码入口：[字幕格式转换](../videotrans/winform/fn_subtitlescover.py)。

### 8.5 合并双语字幕

“合并两个字幕”会把两个 SRT 按行合并，常用于生成双语字幕。

```text
中文.srt
英文.srt
  -> 合并两个字幕
  -> 每条字幕显示两行文本
```

源码入口：[合并双语字幕](../videotrans/winform/fn_hebingsrt.py)。

### 8.6 从视频中分离音频和无声视频

“分离视频到音频”可以从视频里导出 WAV，也可以同时导出无声 MP4。

```text
原视频
  -> WAV 音频
  -> 可选：无声视频
```

适合先把音频拿去降噪、文稿匹配、外部修音，再回来合成。源码入口：[提取音频](../videotrans/winform/fn_audiofromvideo.py)。

### 8.7 混合两路音频

“混合两路音频”把两个音频混成一个 WAV。

```text
旁白.wav
背景音乐.wav
  -> 混音
  -> 一个混合音频.wav
```

源码入口：[混合两路音频](../videotrans/winform/fn_hunliu.py)。

### 8.8 人声和伴奏分离

“人声与伴奏分离”用于把音频或视频拆成更干净的人声、背景或伴奏素材。

```text
带背景音乐的视频/音频
  -> 人声
  -> 伴奏或背景
```

如果你想在配音后尽量保留原视频背景音，主工作台也有背景音相关选项；独立分离工具适合先把素材处理好再进入主流程。源码入口：[人声伴奏分离](../videotrans/winform/fn_separate.py)。

### 8.9 添加水印

“给视频加水印”支持批量选择视频和一张图片，设置位置、偏移和尺寸。

```text
视频 + png/jpg/gif
  -> 左上 / 右上 / 右下 / 左下 / 中心
  -> 带水印 MP4
```

源码入口：[水印](../videotrans/winform/fn_watermark.py)。

### 8.10 按字幕剪辑视频

“根据字幕剪辑视频”会读取 SRT 的每一行时间轴，让你勾选要导出的片段。

```text
视频 + 对应字幕
  -> 勾选字幕行
  -> 输出每行对应的视频片段 / 纯音频 / 无声视频
```

适合做素材切片、口播片段提取、按字幕行导出训练素材。源码入口：[字幕剪辑](../videotrans/component/clip_video.py)。

### 8.11 文稿匹配和时间轴对齐

“文稿匹配和时间轴”适合这种情况：你有一段音频和对应原文，但没有字幕时间轴。

```text
音频 + 原文 TXT
  -> Whisper 识别字符时间点
  -> 与原文做序列匹配
  -> 生成对齐后的 SRT
```

它不是普通翻译工具，而是“给已有文稿补时间轴”。源码入口：[文稿匹配](../videotrans/component/textmatching.py)。

### 8.12 实时语音转文字

“实时语音转文字”使用麦克风输入，实时显示识别文本，并支持导出 TXT、复制、清空。它主要支持中英文实时识别。

```text
麦克风
  -> 实时识别
  -> 文本片段
  -> 导出 TXT
```

源码入口：[实时转写](../videotrans/component/realtime_stt.py)。

## 场景 9：配置、排错与维护

桌面端很多问题不是“流程不会跑”，而是某个外部渠道没有配置、网络不可达、模型不可用、字幕样式不符合成片要求。

### 9.1 渠道配置

把渠道理解成三类插槽：

```text
识别渠道 ASR
  用来把声音变字幕

翻译渠道 Translation
  用来把原文字幕变目标语种字幕

配音渠道 TTS
  用来把字幕或文本变声音
```

主窗口会根据你选择的渠道检查语言、模型、API 配置是否可用。需要 API key、本地服务地址或模型路径的渠道，先到设置菜单对应项里填写。

| 类型 | 典型配置入口 |
|---|---|
| 翻译 | 百度、阿里、腾讯、DeepL、DeepLX、ChatGPT、Azure、Gemini、DeepSeek、OpenRouter、本地 LLM、LibreTranslate、自定义翻译 API 等 |
| TTS | Edge TTS、Azure TTS、OpenAI TTS、ElevenLabs、CosyVoice、GPT-SoVITS、F5-TTS、FishTTS、ChatTTS、Clone、参考音频、TTS API 等 |
| ASR | Faster Whisper、OpenAI Whisper、Whisper.cpp、WhisperX API、Deepgram、FunASR、字节识别、OpenAI 识别 API、自定义 STT API 等 |

不要把“网络代理”和“某个 API 地址”混在一起。代理是全局网络出口，API 地址应该填在对应渠道配置里。

### 9.2 字幕样式

需要硬字幕或视频合成时，打开“字幕样式设置”。它可以调整字体、字号、颜色、描边、阴影、边距、位置，并提供预览。

```text
目标字幕
  -> ASS 样式
  -> 硬字幕烧录
  -> 成片画面
```

源码入口：[字幕样式](../videotrans/component/set_ass.py)。

### 9.3 网络代理

如果模型下载、翻译 API、TTS API 访问慢或失败，先确认是否需要代理。代理格式通常类似 `http://127.0.0.1:端口` 或 socks 代理。

```text
需要代理的情况
  -> 外部 API 访问失败
  -> Hugging Face 模型下载失败
  -> Google 翻译等网络服务不可达

不该填在代理里的内容
  -> ChatGPT API base url
  -> 自定义识别接口地址
  -> 自定义 TTS 接口地址
```

源码入口：[代理设置](../videotrans/component/set_proxy.py)。

### 9.4 高级选项

“选项”窗口保存更底层的全局设置，例如模型列表、Hugging Face token、视频编码、输出目录等。它适合在你已经知道要调整什么时使用。

```text
普通任务效果问题
  -> 优先调整主窗口选项

模型列表、编码、token、全局路径问题
  -> 再打开选项窗口
```

源码入口：[高级设置](../videotrans/winform/setini.py)。

### 9.5 清理缓存和重试失败

主流程会生成临时音频、字幕、缓存和任务中间文件。出现中断、输出异常、临时文件过多时，可以用“清理缓存”。批量任务里如果部分失败，优先使用“重试失败”，不要整批从头跑。

### 9.6 帮助菜单

帮助菜单不是生产链路，但它覆盖新用户常见外部问题：

| 入口 | 解决什么 |
|---|---|
| 文档 | 查看官方使用说明 |
| 模型下载失败解决方案 | 模型下载、镜像、网络问题 |
| Google 翻译教程 | Google 翻译相关配置 |
| CUDA 与 cuDNN | GPU 加速依赖 |
| FFmpeg | 音视频处理依赖 |
| Github 仓库、提交 issue、论坛/博客 | 源码、反馈和社区支持 |
| 免责声明、关于 | 使用边界和项目信息 |

## 主工作台高级选项怎么选

这些选项不需要第一次全部打开。你可以按问题来选。

| 问题 | 优先看这些选项 |
|---|---|
| 识别慢 | 模型大小、CUDA、识别渠道 |
| 识别错字多 | 源语言、模型、降噪、标点修复、二次断句 |
| 多人说话混在一起 | 说话人分离、说话人数 |
| 翻译术语不稳定 | 术语表、AI 完整 SRT 输入、翻译渠道 |
| 配音时长对不上字幕 | 配音自动适配、去除中间静音、语速 |
| 配音比视频长 | 视频自动变速、合成工具里的音频处理策略 |
| 想保留原背景音乐 | 人声分离、嵌入背景音、背景音乐、循环背景音、背景音量 |
| 字幕太长或样式不好看 | 字幕类型、输出 SRT、字幕样式、最大行宽 |
| 只想要最终 MP4 | 只输出 MP4 |
| 跑完自动关机 | 关机选项 |

## 完整练习路线

如果你想按教程把桌面端功能真正跑熟，可以按这个顺序做：

```text
第 1 轮：跑通主线
  标准功能模式
  -> 单个 MP4 做目标语种配音 MP4

第 2 轮：拆开主线
  语音识别文本
  -> 文本或 SRT 翻译
  -> 从文本到语音
  -> 视频字幕合并

第 3 轮：处理已有素材
  字幕格式转换
  -> 合并双语字幕
  -> 批量视频 SRT 合并
  -> 批量视频音频合并

第 4 轮：处理复杂素材
  人声伴奏分离
  -> 分离视频到音频
  -> 文稿匹配和时间轴
  -> 根据字幕剪辑视频
  -> 添加水印

第 5 轮：处理生产问题
  代理
  -> 渠道配置
  -> 字幕样式
  -> 高级选项
  -> 清理缓存和重试失败
```

完成这 5 轮后，你不需要记住每个按钮，只需要记住这个判断方式：

```text
要成片，走标准功能模式或视频字幕合并。
要中间素材，走识别、翻译、配音三个独立工具。
要修素材，走工具菜单。
要修渠道和环境，走设置和帮助菜单。
```
